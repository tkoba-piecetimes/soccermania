# SERP分析メモ: サッカー 練習メニュー 大学生（2026-11-13）

## 確認した上位の顔ぶれ
- JFA 中学校部活動サッカー指導の手引き（6項目・時間配分・週間配置）
- JFA ナショナルトレセンU-14 トレーニングメニュー資料（ポゼッション段階構成）
- 個人指導者サイト（5対3・5対5+2 など小中学生向けのポゼッション練習）

## 共通点（検索意図の正解）
1. 具体的なドリル名・人数・コート寸法の羅列が中心（小中学生・ジュニア向けが大半）
2. 練習の構成（ウォームアップ→技術→ゲーム→クールダウン）と時間配分を示す
3. 週間の組み方は「試合1・練習4・休養2」程度の一般論

## 欠けている要素（差別化点）
1. 大学生向けに公開された標準メニューが見当たらない。中学校向け資料を「型」として借りる前提を明示する記事がない
2. 公式戦の間隔（連戦・空白期間）といったリーグ日程の一次データと練習設計を結び付けた記事がない -> 当サイトの matches.json から試合間隔を集計して差別化
3. ウォームアップ（FIFA 11+）と暑熱対策を、メニュー作成者（学生コーチ・幹部）の視点で週間計画に組み込む手順がない

## 方針
- 個別ドリルの羅列はしない。「型・日程・安全」で組み立て方を示す（既存の個人練習・練習量・怪我予防記事と1意図で分離）
- 数値は JFA / スポーツ安全協会 / 当サイトデータのみ。WBGT区分の具体数値は画像でしか確認できなかったため本文に書かない
- 内部リンク: kanto-1/kansai-1/hokushinetsu-1 の schedule、kanto-1 standings、glossary、既存記事6本
