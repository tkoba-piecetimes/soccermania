# SERP分析メモ: サッカー スパイク 選び方

- **上位の顔ぶれ**: ミズノ公式（jpn.mizuno.com）、マイベスト（my-best.com、AG用スパイクのおすすめランキング）、アディダス公式、スーパースポーツゼビオ、クーバー・コーチング、0014のblog（個人ブログ、土用/人工芝用を別記事で詳解）、Soccer-dribbler、Soccer Book Library等。ブランド公式・通販メディア・個人ブログが中心で、大学サッカー部を運営する媒体は上位に見当たらない。
- **検索意図の正解（共通点）**: HG（土）/FG（天然芝）/AG（人工芝）/MG（マルチ）のグラウンド対応表記の違い、アッパー素材（天然皮革・人工皮革）、スタッド形状、サイズ選び（つま先0.5〜1cmの余裕）が主要な選定基準として共通して挙げられている。ミズノ公式は部活・クラブチーム所属者を想定し練習頻度の高さに言及しているが、あくまで自社製品訴求が主目的。
- **欠けている要素（差別化点）**: 「大学によって・大学のリーグ/対戦相手によって人工芝と土グラウンドが混在する」という大学サッカー特有の環境（自分のホームは人工芝でも遠征先は土、または逆のケースがある）を前提にした選び方コンテンツは無い。複数足を使い分ける際の優先順位や予算配分、遠征先グラウンドの調べ方（リーグの日程・チームページとの連携）まで踏み込んだ記事は見当たらず、本サイトの一次データ（日程・チーム一覧ページ）と組み合わせて差別化できる。
